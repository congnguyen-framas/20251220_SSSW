System Overview

ShotWeightWindow is the main screen of the SSSW application (Shot-weight Scale Station) – a WPF interface running on workstations on the production floor. QC / IT staff use this screen to:

  • Weigh injection molding shots step by step according to the production BOM.
  • Automatically read data from the digital scale, QR/Barcode scanner, and employee RFID cards.
  • Calculate Part Weight, Runner Weight, Total Weight for each step.
  • Save results to the database (table FT600) and update Hydra status (FT601).
  • Compare against standard values (STD) within tolerance thresholds: ±1% (OK) / ±3% (Warn).

2.4 Dependency Injection

ShotWeightViewModel is resolved from the DI container with the following dependencies:

  • IDbContextFactory<DbContextDogeWH> – creates a DbContext per-operation (thread-safe)
  • IServiceProvider – resolves auxiliary forms (frmMainView, frmUpdateMasterData)
  • ILogger<ShotWeightViewModel> – error logging (Microsoft.Extensions.Logging)

Commands use RelayCommand (sync) and AsyncRelayCommand (async) following pure MVVM pattern.

Business Logic

4.1 Startup (InitializeAsync)

1
Initialize AutoUpdater (DownloadPath, events).
2
Query DB: sp_MaterialGetCompanyName → _mesocomp; sp_MaterialGetMesoyear → _mesoYear.
3
Map mesocomp → EnumLocation → WindowTitle (fVN / fKV / fFT / fIN / fGE – Shotweight Station).
4
Read FT608_Config by Environment.MachineName → deserialize ConfigModel. If not found → INSERT defaults.
5
Call ApplyHardwareConfigAction → code-behind initializes BarcodeDriver, RfidDriver, ScaleDriver.
6
Set UsagePct = ConfigSystem.PercentOfUserNonWoven, ReadOnly = ConfigSystem.EnableReadScale.
7
Call LoadDataAsync().

4.2 LoadDataAsync – Load master data

Uses a CancellationTokenSource linked with a timeout (default 30s). Cancels any previous request before starting.

1
Show overlay + enable Cancel button.
2
Task.Run: query FT601s WHERE C021=true AND Mesoyear=_mesoYear.
3
Project → List<StepSelectModel> → StepCodeMaster (ItemsSource for LookUpEdit).
4
Dispatch to UI thread → update StepCodeMaster. Hide overlay.

4.3 GetDataAsync – Build step list (new session)

1
ResetNewLoop() – clear previous state.
2
Query FT601 by C007 (FGItemCode) → _stepItemCodeScale.
3
Call sp_getBomWinlineOfItemFG(@itemFG) → _allStepsFG.
4
For each BOM step: find the matching FT601 in _dataHydra, create a temporary FT600 (AllowScale by rule: REX/Z-VHXXXXXX=true, unmatched code=false).
5
Handle multi-size molds: find sameMolds by MoldId+Machine+prefix → add to _scaleData.
6
Sort _scaleDataFinal by C015 (sequence) → C027. Pre-fill values for Stud/Logo/Cleat_Ring/REX from DB (most recent record).
7
Check previous steps: if C021 == 0 → warn "The previous step has not been weighed."

4.4 RFID – Employee Authentication

1
Driver reads card → OnRfidValueChanged(rfidCode).
2
Query FT029_Operator_RFID WHERE C000.Contains(rfidCode).
3
Check DepartmentInfor: must belong to IT or QC (FT031). If not → reject, clear RFID.
4
If valid: RfidName = C001, UserName = "Code · Name".
5
If not in DB: Focus tbRFIDName → type name + Enter → OnRfidNameEnterAsync → INSERT into FT029.

4.5 Barcode – Find Step from QR

1
Driver reads → OnBarcodeScannedAsync(barcode).
2
Query FT606_Label WHERE c001 = barcode → _labelInfo.
3
Find _stepSelected in _dataHydra by _labelInfo.c000 (FT601.Id).
4
FilterStepCombo → set LookUpEdit → TriggerStepSelectionAsync.

Calculation Formulas (ExecuteSave)

When Save is pressed, ExecuteSave branches by material type:

5.1 Injection Items – 1st Weighing (C024 == 0)

C024
C024 = ScaleValue
Total weight after ejection (part + runner). Unit: grams. This is the first weighing.

5.2 Injection Items – 2nd Weighing (C024 > 0)

Remove the runner, keep only the part on the scale:

C023
C023 = ScaleValue
Total Part Weight (g/prs) – read directly from the scale.
C022 (Runner=YES)
C022 = Round( (C024 − C023 × prsShot) / prsShot, 3 )
Runner weight (g/prs). prsShot = _articlePaisShotFinaly. If Runner = NO → C022 = 0.
C021
C021 = C023 − Σ C023prev − Σ C023non-inj
Part Weight for this step (g/prs).
• Σ C023prev: sum of C023 for all steps with C015 = current_C015 − 1.
• Σ C023non-inj: sum of C023 for REX / Z-VHXXXXXX steps at the same C015.
C036 (Studs/Logo/Cleat_Ring)
C036 = Round( ScaleValue / prsShot, 2 )
Weight per piece (g) for special accessories. For other steps: C036 = 0.

5.3 Non-injection (REX…) – Receptacle (catCheck == null)

C024 = C023 = C021
= ScaleValue
100% of material is part weight. No waste.
C036
C036 = Round( ScaleValue / C025, 2 )
C025 = quantity.

5.4 Non-injection (REX…) – Nonwoven / Mesh (catCheck != null, uses Usage %)

usage
usage = Round( (ScaleValue × _percentOfUsage / 100) / C028, 3 )
Actual used portion (g/prs). C028 = prsShot.
unusage
unusage = (ScaleValue − usage × C028) / C028
Unused portion (waste, g/prs).
C024
C024 = ScaleValue
Total raw material weight.
C023 = C021
= usage
Part weight = the portion actually used.
C022
C022 = unusage
Excess = unused portion.
C036
C036 = Round( usage / 2, 2 )
Weight per foot (divided by 2 since 1 pair = 2 feet).

5.5 Multi-size Mold

When sameMolds.Count > 1 (multiple sizes sharing one mold):

sumPW
sumPW = Σ( C023i × C028i )
Total part weight × pairs across all sizes.
pairShot
pairShot = Σ C028i
Total pairs across all sizes.
C024 (each size)
C024 = _rowSelected.C024
Shared total weight value.
C022 (each size)
C022 = (C024 − sumPW) / pairShot (if C023 > 0, else 0)
Runner weight distributed by pairs.

5.6 Cascade Update (recalculate subsequent steps)

After Save, subsequent steps with C024 > 0 are recalculated:

C021 (same seq)
C021 = C023 − _rowSelected.C023
C022 (same seq)
C022 = C024 − C021
C021 (later seq)
C021 = C023 − prev.C023
prev = the immediately preceding step.
C022 (later seq)
C022 = C024 − C021

5.7 Tolerance and Reference Panel Colors

Δ (Delta)
Δ = Actual − STD
STD = C024/C023/C021/C022 value from the most recent weighing in DB.
Δ% (DeltaPct)
Δ% = (Actual − STD) / STD × 100

LevelConditionCell BGText ColorScale Card Border
IdleSTD or Actual not yet available#F5F5F5#546E7A#CFD8DC
OK|Δ%| ≤ DeltaLevel1 (typically 1%)#D4F7DC#1B5E20#4CAF50

Confirm & DB Save Flow (ExecuteConfirmAsync)

1
Check _operatorInfo.Id != Guid.Empty – RFID must have been scanned and validated.
2
Check multi-size molds (sameMolds): if > 0, skip the completeness check.
3
Check each row with AllowScale=true: C023 == 0 AND C024 == 0 (REX) → warn "Scale not completed for step: XXX".
4
Filter: insert = _scaleDataFinal WHERE AllowScale=true AND C021 > 0.
5
Set metadata: C010=EmployeeCode, C011=EmployeeName, CreatedDate=now, CreatedMachine, Mesocomp, Mesoyear.
6
Transaction: db.FT600s.AddRangeAsync(insert).
7
FT601s.ExecuteUpdateAsync: SET C017=true, ModifiedDate, ModifiedMachine WHERE C004=_stepItemCodeScale.C004 AND C007=_stepItemCodeScale.C007 AND C017=false.
8
SaveChangesAsync + CommitAsync. On error → RollbackAsync.
9
Reset: clear _labelInfo, call ClearStepComboAction, ResetNewLoop().

UI User Guide

8.1 Startup and Login

1
Launch SSSW – wait for the "Loading…" overlay to disappear.
2
Check device dots: green = connected, red = disconnected.
3
Scan RFID card (or type Employee ID → Enter). Employee name appears in the Employee Name field and the top-right of the title bar.
Note: Only IT / QC staff are authorized to weigh. First-time registration: type name in Employee Name → Enter → confirm "Yes".

8.2 Select a Production Step

Method 1 – Scan QR/Barcode: Click the "Barcode / QR Scan" field → scan → the system auto-selects the step.

Method 2 – Manual LookUpEdit: Click "Select Step" → popup opens → type a keyword in the auto-filter → click the desired row.

After selection: the left panel fills in automatically, the Total Steps grid shows the BOM, and the History panel updates.

8.3 Performing the Weighing

Injection – 1st weighing: Total Weight Injection (C024)

1
Place the entire shot (part + runner) on the scale. Wait for the "Stable Value" badge to turn green.
2
Click Scale in the grid, or press the Save button in the bottom bar.
3
The "TOTAL WEIGHT INJECTION" column updates in the grid.

Injection – 2nd weighing: Total Part Weight (C023)

1
Remove the runner, keep only the part. Wait for stability → press Save.
2
C023, C022, C021 are calculated and displayed. The Reference Panel colors by tolerance.

Non-injection (REX) – Single weighing

1
Place the material on the scale → wait for stability → press Save.
2
System automatically calculates C021/C022/C023/C024 using receptacle or nonwoven logic.

8.5 Manual Entry (when scale is disconnected)

1
Click the large scale number field (Consolas 44pt).
2
Type a numeric value (e.g. 36.5) – only digits and decimal point are accepted.
3
Press Enter → the system processes it as if received from the real scale.
A yellow warning tooltip appears automatically for invalid characters (auto-closes after 2 seconds).

8.6 Confirm and Save (Confirm)

1
Ensure a valid RFID has been scanned.
2
Ensure all AllowScale=true steps have been weighed.
3
Click Confirm → system saves to DB, shows success message, resets the screen.

8.7 Hydra Sync

1
Click the ⚡ Hydra button in the title bar.
2
Calls sp_GetFullStepItemHydraIsRun → INSERTs new FT601 records.
3
Automatically calls LoadDataAsync to refresh the LookUpEdit.
