1. Tổng quan hệ thống

ShotWeightWindow là màn hình chính của ứng dụng SSSW (Shot-weight Scale Station) — giao diện WPF chạy trên máy trạm tại xưởng sản xuất.

  • Cân từng bước shot nhựa theo BOM sản xuất.
  • Tự động đọc dữ liệu từ cân điện tử, máy quét QR/Barcode, và thẻ RFID nhân viên.
  • Tính toán Part Weight (C021), Runner Weight (C022), và Total Part Weight (C023) cho từng bước.
  • Lưu kết quả vào FT600 và cập nhật trạng thái Hydra trong FT601.
  • So sánh giá trị thực tế với tiêu chuẩn (STD) trong ngưỡng dung sai: ±1% OK / ±3% WARN / >3% ERR.

3. Nghiệp vụ (Business Logic)

3.1 Khởi động (InitializeAsync)

1
Khởi tạo AutoUpdater (DownloadPath, events).
2
Query DB: sp_MaterialGetCompanyName → _mesocomp; sp_MaterialGetMesoyear → _mesoYear.
3
Map mesocomp → EnumLocation → WindowTitle (ví dụ: fVN – Shotweight Station).
4
Đọc FT608_Config theo Environment.MachineName → deserialize ConfigModel. Nếu không tìm thấy → INSERT mặc định.
5
Gọi ApplyHardwareConfigAction → code-behind khởi tạo BarcodeDriver, RfidDriver, ScaleDriver.
6
Set UsagePct = ConfigSystem.PercentOfUserNonWoven, ReadOnlyScale = !ConfigSystem.EnableReadScale.
7
Gọi LoadDataAsync().

3.2 LoadDataAsync — Tải dữ liệu master

1
Hiển thị overlay + bật nút Cancel. Dùng CancellationTokenSource với timeout 30 giây.
2
Task.Run: query FT601s WHERE C021=true AND Mesoyear=_mesoYear.
3
Project → List<StepSelectModel> → StepCodeMaster (ItemsSource cho LookUpEdit).
4
Dispatch về UI thread → cập nhật StepCodeMaster. Ẩn overlay.

3.3 GetDataAsync — Xây dựng danh sách Step

1
ResetNewLoop() — xóa trạng thái phiên trước.
2
Query FT601 theo C007 (FGItemCode) → _stepItemCodeScale.
3
Gọi sp_getBomWinlineOfItemFG(@itemFG) → _allStepsFG.
4
Với mỗi bước BOM: tìm FT601 tương ứng trong _dataHydra, tạo FT600 tạm (AllowScale: REX/Z-VHXXXXXX=true, không khớp=false).
5
Xử lý khuôn nhiều size: tìm sameMolds theo MoldId+Machine+prefix → thêm vào _scaleData.
6
Sắp xếp _scaleDataFinal theo C015 → C027. Điền sẵn giá trị Stud/Logo/Cleat_Ring/REX từ DB.
7
Kiểm tra bước trước: nếu C021 == 0 → cảnh báo "Bước trước chưa được cân."

3.4 RFID — Xác thực nhân viên

1
Driver đọc thẻ → OnRfidValueChanged(rfidCode).
2
Query FT029_Operator_RFID WHERE C000.Contains(rfidCode).
3
Kiểm tra DepartmentInfor: phải thuộc IT hoặc QC (FT031). Nếu không → từ chối, xóa RFID.
4
Nếu hợp lệ: RfidName = C001, UserName = "Mã · Tên" — hiển thị trên title bar kèm chấm trạng thái.
5
Nếu chưa có trong DB: Focus tbRFIDName → nhập tên + Enter → OnRfidNameEnterAsync → INSERT vào FT029.
Click vào tên nhân viên trên title bar sẽ mở dialog frmRfidInput để nhập RFID thủ công.

3.5 Barcode — Tìm Step từ mã QR

1
Driver đọc → OnBarcodeScannedAsync(barcode).
2
Query FT606_Label WHERE c001 = barcode → _labelInfo.
3
Tìm _stepSelected trong _dataHydra theo _labelInfo.c000 (FT601.Id).
4
FilterStepCombo → set LookUpEdit → TriggerStepSelectionAsync.

Nhập tay: gõ barcode vào ô Barcode / QR Scan ở panel bên trái → nhấn Enter.

4. Công thức tính

Khi nhấn Save, ExecuteSave phân nhánh theo loại vật liệu:

4.1 Hàng Injection — Cân lần 1 (C024 == 0)

Gán tổng khối lượng phun:
C024 = ScaleValue

4.2 Hàng Injection — Cân lần 2 (C024 > 0)

Runner=YES:
C023 = ScaleValue
C022 = Round( (C024 − C023 × prsShot) / prsShot , 3 )
C021 = C023 − Σ C023_bướcTrước − Σ C023_non-inj

Runner=NO:
C022 = 0

Trong đó: prsShot = _articlePaisShotFinaly (C028); Σ C023_bướcTrước = tổng C023 ở bước trình tự C015−1; Σ C023_non-inj = tổng C023 của bước REX/Z-VH cùng trình tự.

Với Studs, Logo, Cleat_Ring: C036 = Round(ScaleValue / prsShot, 2)

4.3 Non-Injection (REX) — Receptacle (catCheck == null)

C024 = C023 = C021 = ScaleValue
C036 = Round(ScaleValue / C025, 2) // C025 = số lượng

4.4 Non-Injection (REX) — Vải không dệt / Lưới (catCheck != null)

usage = Round( (ScaleValue × _percentOfUsage / 100) / C028, 3 )
unusage = (ScaleValue − usage × C028) / C028

C024 = ScaleValue
C023 = C021 = usage
C022 = unusage
C036 = Round(usage / 2, 2) // mỗi foot

4.5 Khuôn nhiều Size

sumPW = Σ( C023_i × C028_i )
pairShot = Σ C028_i

C024[mỗi size] = _rowSelected.C024
C022[mỗi size] = (C024 − sumPW) / pairShot // nếu C023 > 0, ngược lại = 0

4.6 Cập nhật lan truyền (Cascade Update)

Cùng trình tự: C021 = C023 − _rowSelected.C023 ; C022 = C024 − C021
Trình tự sau: C021 = C023 − prev.C023 ; C022 = C024 − C021

4.7 Hệ thống dung sai

Δ = Actual − STD
Δ% = (Actual − STD) / STD × 100
MứcĐiều kiệnBadgeNềnViền
IdleSTD hoặc Actual chưa cóIDLE#F5F5F5#CFD8DC
OK|Δ%| ≤ 1%OK#D4F7DC#4CAF50
WARN1% < |Δ%| ≤ 3%WARN#FFF3CD#FF9800
ERR|Δ%| > 3%ERR#FDE8E8#F44336

Màu viền/nền Scale Card = mức xấu nhất của 4 dòng Reference.

5. Xác nhận & Luồng CSDL

Các bước ExecuteConfirmAsync:

1
Kiểm tra _operatorInfo.Id != Guid.Empty — phải đã quét và xác thực RFID.
2
Kiểm tra khuôn nhiều size (sameMolds): nếu > 0, bỏ qua kiểm tra tính đầy đủ.
3
Mỗi hàng có AllowScale=true: nếu C023 == 0 AND C024 == 0 → cảnh báo "Chưa cân bước: XXX".
4
Lọc: insert = _scaleDataFinal WHERE AllowScale=true AND C021 > 0.
5
Gán metadata: C010=MãNV, C011=TênNV, CreatedDate=now, CreatedMachine, Mesocomp, Mesoyear.
6
Transaction: db.FT600s.AddRangeAsync(insert).
7
FT601s.ExecuteUpdateAsync: SET C017=true, ModifiedDate, ModifiedMachine.
8
SaveChangesAsync + CommitAsync. Nếu lỗi → RollbackAsync.
9
Reset: xóa _labelInfo, gọi ClearStepComboAction, ResetNewLoop().

8. Hướng dẫn sử dụng

8.1 Khởi động & Đăng nhập

1
Mở SSSW — chờ overlay "Loading…" biến mất.
2
Kiểm tra chấm trạng thái thiết bị: 🟢 xanh = đã kết nối, 🔴 đỏ = mất kết nối.
3
Quét thẻ RFID — hoặc click vào tên nhân viên trên title bar để mở dialog frmRfidInput. Tên NV hiển thị kèm chấm trạng thái.
Lưu ý: Chỉ nhân viên IT / QC được phép sử dụng. Người dùng lần đầu: nhập tên → Enter → xác nhận "Yes".

8.2 Chọn bước sản xuất

Cách 1 – Quét QR/Barcode: Click vào ô "Barcode / QR Scan" → quét → bước tự động được chọn.

Cách 2 – Nhập bàn phím: Gõ barcode vào ô → nhấn Enter.

Cách 3 – Thủ công: Click "Select Step" → popup lọc kiểu Excel → click hàng cần chọn.

8.3 Quy trình cân

Injection — Cân lần 1 (C024)

1
Đặt cả shot (phần + runner) lên cân. Chờ badge "Stable Value" → xanh.
2
Click [Scale] trong hàng grid HOẶC nhấn Save.
3
Cột "TOTAL INJECTION (g)" cập nhật.

Injection — Cân lần 2 (C023)

1
Lấy runner ra, chỉ giữ phần trên cân. Chờ ổn định → nhấn Save.
2
C023, C022, C021 được tính toán. Panel Reference đổi màu theo dung sai.

Non-Injection (REX) — Cân một lần

1
Đặt vật liệu lên cân → chờ ổn định → nhấn Save (một lần duy nhất).
2
Hệ thống tự tính theo công thức receptacle hoặc nonwoven.

8.6 Xác nhận và Lưu vào CSDL

3
Click Confirm → lưu vào DB → thông báo thành công → màn hình reset.

8.7 Đồng bộ Hydra

1

2
Gọi sp_GetFullStepItemHydraIsRun → INSERT bản ghi FT601 mới.
3
Tự động gọi LoadDataAsync để làm mới LookUpEdit.
