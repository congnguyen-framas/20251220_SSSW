1. Tổng quan hệ thống

ShotWeightWindow là cửa sổ chính của trạm cân Shot Weight (SSSW). Màn hình cho phép công nhân/QC cân trọng lượng nguyên liệu tại từng bước công đoạn trong quá trình sản xuất giày theo lệnh Hydra. Kết quả cân được lưu vào database để truy xuất, kiểm tra chất lượng và theo dõi tiêu hao vật tư.

1.1 Mục đích sử dụng

  • Cân và ghi nhận Total Weight Injection và Part Weight theo từng step BOM.
  • Tính toán tự động: Part Weight (C021), Runner Weight (C022), Total Part Weight (C023).
  • So sánh giá trị cân thực tế với giá trị chuẩn (STD) theo dung sai ±1% / ±3% với màu sắc trực quan.
  • Lưu dữ liệu vào bảng FT600 (database DogeWH) với đầy đủ thông tin operator, máy, lô sản xuất.
  • Đồng bộ dữ liệu lệnh sản xuất từ hệ thống Hydra ERP vào bảng FT601.

4. Logic nghiệp vụ & Công thức tính toán

4.1 Phân loại vật liệu (Material Type)

LoạiĐiều kiện nhận dạngXử lý cân
Injection (ép nhựa) C002 không bắt đầu bằng "REX" 2 lần cân: lần 1 = Total Injection Weight; lần 2 = Total Part Weight
Non-Injection – Full (Receptacle) C002 bắt đầu "REX" VÀ không thuộc category partial 1 lần cân: toàn bộ = part weight
Non-Injection – Partial (Nonwoven/Mesh) C002 bắt đầu "REX" VÀ thuộc CategoryOfNonInjectionUsagePartial 1 lần cân: chỉ dùng UsagePct% của tổng

4.2 Công thức tính toán chi tiết

4.2.1 Injection – Lần cân thứ nhất (đặt toàn bộ shot lên cân)

C024 (Total Weight Injection):
C024 = ScaleValue

4.2.2 Injection – Lần cân thứ hai (tháo runner, chỉ để part)

C023 (Total Part Weight – đọc từ cân):
C023 = ScaleValue
C022 (Runner Weight g/prs) – khi Runner = YES:
C022 = ( C024 − C023 × pairs ) / pairs
C022 (Runner Weight) – khi Runner = NO:
C022 = 0
C021 (Part Weight thực tế bước này g/prs):
C021 = C023(bước này) − Σ C023(bước trước: C015 = currentStep.C015 − 1) − Σ C023(REX / Z-VHXXXXXX cùng C015)
pairs = C028 (Pairs/Shot của bước đang cân – _articlePaisShotFinaly).
Bước trước = tất cả records trong _scaleDataFinal có C015 = currentStep.C015 − 1.
Non-injection cùng bước = records có C002 bắt đầu "REX" hoặc C002 = "Z-VHXXXXXX" và cùng C015.

4.2.3 Non-Injection – Full (Receptacle – REX không thuộc partial)

C024 = ScaleValue
C023 = ScaleValue
C021 = ScaleValue
C036 = Round( ScaleValue / Quantity, 2 ) ← trọng lượng mỗi piece

4.2.4 Non-Injection – Partial (Nonwoven/Mesh – REX thuộc partial category)

Tính usage và unusage trước:
usage = Round( ScaleValue × UsagePct% / 100 / pairs, 3 )
unusage = ( ScaleValue − usage × pairs ) / pairs

Ghi vào record:
C024 = ScaleValue
C023 = usage
C021 = usage
C022 = unusage
C036 = Round( usage / 2, 2 ) ← chia 2 cho left/right
UsagePct% = GlobalVariable.ConfigSystem.PercentOfUserNonWoven (mặc định) hoặc giá trị user nhập vào ô "Usage %" rồi Enter.

4.2.5 Multi-size Mold (nhiều size trên 1 khuôn)

Khi phát hiện cùng MoldId (C020) và Machine (C004) có nhiều size khác nhau trên cùng sequence step, hệ thống phân bổ C024 chung và tính C022 theo tỉ lệ:

sumPW = Σ ( C023[i] × C028[i] ) ← tổng part weight × pairs của tất cả size trên khuôn
pairShot = Σ C028[i] ← tổng pairs tất cả size

Với mỗi size (i):
C024[i] = C024(row được cân) ← dùng chung C024
C022[i] = ( C024 − sumPW ) / pairShot (nếu C023[i] > 0, ngược lại = 0)

4.2.6 Cascade cập nhật các bước sau (ExecuteSave)

Sau khi Save một bước, hệ thống tự động cập nhật C021/C022 cho các bước tiếp theo đã có C024 > 0:

Nếu item.C015 == _rowSelected.C015 (cùng sequence):
  item.C021 = item.C023 − _rowSelected.C023
  item.C022 = item.C024 − item.C021

Nếu item.C015 > _rowSelected.C015 (bước tiếp):
  item.C021 = item.C023 − prev.C023 (prev = bước liền trước)
  item.C022 = item.C024 − item.C021
Điều kiện cascade: Chỉ áp dụng cho injection items (không phải REX, Stud, Inlay, Ring) và không cùng prefix mold với bước đang cân.

4.2.7 Studs / Logo / Cleat_Ring (C036)

C036 = Round( ScaleValue / pairs, 2 ) ← khi step name bắt đầu "Studs", "Logo", hoặc "Cleat_Ring"

4.3 Hệ thống dung sai (Tolerance)

Giá trị trong Reference Panel được tô màu tự động khi so sánh Actual vs STD (giá trị lần cân gần nhất từ lịch sử):

MứcĐiều kiệnHiển thịÝ nghĩa
IDLE Chưa có STD hoặc Actual = 0 Xám nhạt Chưa có dữ liệu để so sánh
OK ✓ |Δ%| ≤ 1% Xanh lá #4CAF50 Trong ngưỡng an toàn
WARN ⚠ 1% < |Δ%| ≤ 3% Cam #FF9800 Cảnh báo – cần kiểm tra
ERROR ✗ |Δ%| > 3% Đỏ #F44336 Vượt ngưỡng – cần xem xét
Δ% = ( Actual − STD ) / STD × 100

ScaleCard (khung cân số lớn) đổi màu nền và viền theo mức tolerance worst-case trong 4 Reference Rows.

7.2 Cân vật liệu Non-Injection (REX items)

  • Chọn step có mã bắt đầu "REX" (Nonwoven, Mesh, Receptacle...).
  • Nếu là Partial (Nonwoven/Mesh): Kiểm tra ô Usage % – nhập đúng phần trăm rồi Enter trước khi Save.
  • Đặt vật liệu lên cân → nhấn [↓ Save] (chỉ 1 lần).
  • Hệ thống tự tính usage/unusage theo công thức Partial hoặc Full.

7.3 Điều chỉnh Partitioning (Adj.)

  • Tick checkbox Adj. bên cạnh ô Partitioning để mở chế độ chỉnh sửa.
  • Nhập số đôi/shot mới rồi nhấn Enter.
  • Hệ thống cập nhật C028 và tính lại giá trị liên quan.
Lưu ý: Chỉ điều chỉnh khi có thay đổi khuôn hoặc lệnh đặc biệt. Giá trị mặc định lấy từ FT601.

7.4 Nhập tay giá trị cân

  • Khi cân điện tử ngắt kết nối hoặc EnableReadScale=false: ô Scale Value có thể nhập tay.
  • Chỉ nhận ký tự số và dấu . – ký tự khác bị chặn với tooltip cảnh báo màu vàng.
  • Nhấn Enter trong ô Scale Value → hệ thống xử lý như nhận giá trị từ hardware.

8. Cấu hình hệ thống (ConfigSystem)

Config được lưu trong bảng FT608 theo MachineName, dạng JSON (ConfigModel). Truy cập qua GlobalVariable.ConfigSystem.

Cấu hìnhTác dụng
Scanner.Enable / Scanner.ReadOnlyBật/tắt Barcode scanner (Zebra CoreScanner SDK). ReadOnly = chỉ đọc không xử lý.
RFID.Enable, Rfid_Com, Rfid_AutoFindCom, Rfid_Caption, Rfid_ManufactCấu hình RFID reader qua COM port. AutoFindCom=true = tự tìm COM theo Caption/Manufacturer.
Scale.Enable, IP, Port, TimeScan (ms), CalibZero, CalibGain, DecimalNum, ModelName, CheckStable, CheckTareCấu hình cân điện tử qua TCP/IP. TimeScan = chu kỳ polling. CalibZero/CalibGain = hiệu chỉnh.
EnableReadScaletrue = dùng hardware scale (ReadOnly TextBox); false = nhập tay (editable TextBox)
PercentOfUserNonWovenPhần trăm sử dụng mặc định cho Nonwoven/Mesh (vd: 70)
CategoryOfNonInjectionUsagePartialList CategoryCode áp dụng công thức Partial (Nonwoven, Mesh, ...)
UpdatePathURL XML file cho AutoUpdaterDotNET kiểm tra phiên bản mới
Lưu ý: Nếu không tìm thấy config cho MachineName hiện tại, hệ thống tự động tạo record mới với ConfigModel mặc định trong FT608.
