1. System Overview

ShotWeightWindow is the main screen of the Shot Weight Station (SSSW). The screen allows QC / production operators to weigh material at each production step according to the Hydra work order BOM. Weighing results are stored in the database for retrieval, quality inspection, and material consumption tracking.

1.1 Purpose

  • Weigh and record Total Weight Injection and Part Weight for each BOM step.
  • Automatic calculation: Part Weight (C021), Runner Weight (C022), Total Part Weight (C023).
  • Compare actual weighed values against standard (STD) within tolerance ±1% / ±3% with visual color coding.
  • Save data to table FT600 (DogeWH database) with full operator, machine, and production batch information.
  • Synchronize production order data from the Hydra ERP system into table FT601.

4. Business Logic & Calculation Formulas

4.1 Material Classification

TypeIdentification ConditionWeighing Process
Injection (plastic molding) C002 does not start with "REX" 2 weighings: 1st = Total Injection Weight; 2nd = Total Part Weight
Non-Injection – Full (Receptacle) C002 starts with "REX" AND does not belong to partial category 1 weighing: entire weight = part weight
Non-Injection – Partial (Nonwoven/Mesh) C002 starts with "REX" AND belongs to CategoryOfNonInjectionUsagePartial 1 weighing: only UsagePct% of total is used

4.2 Detailed Calculation Formulas

4.2.1 Injection – 1st Weighing (place entire shot on scale)

C024 (Total Weight Injection):
C024 = ScaleValue

4.2.2 Injection – 2nd Weighing (remove runner, keep only part)

C023 (Total Part Weight – read from scale):
C023 = ScaleValue
C022 (Runner Weight g/prs) – when Runner = YES:
C022 = ( C024 − C023 × pairs ) / pairs
C022 (Runner Weight) – when Runner = NO:
C022 = 0
C021 (Actual Part Weight for this step, g/prs):
C021 = C023(this step) − Σ C023(previous step: C015 = currentStep.C015 − 1) − Σ C023(REX / Z-VHXXXXXX same C015)
pairs = C028 (Pairs/Shot of the step being weighed – _articlePaisShotFinaly).
Previous step = all records in _scaleDataFinal with C015 = currentStep.C015 − 1.
Non-injection same step = records with C002 starting "REX" or C002 = "Z-VHXXXXXX" and same C015.

4.2.3 Non-Injection – Full (Receptacle – REX not in partial)

C024 = ScaleValue
C023 = ScaleValue
C021 = ScaleValue
C036 = Round( ScaleValue / Quantity, 2 ) ← weight per piece

4.2.4 Non-Injection – Partial (Nonwoven/Mesh – REX in partial category)

Calculate usage and unusage first:
usage = Round( ScaleValue × UsagePct% / 100 / pairs, 3 )
unusage = ( ScaleValue − usage × pairs ) / pairs

Write to record:
C024 = ScaleValue
C023 = usage
C021 = usage
C022 = unusage
C036 = Round( usage / 2, 2 ) ← divide by 2 for left/right foot
UsagePct% = GlobalVariable.ConfigSystem.PercentOfUserNonWoven (default) or value entered by user in "Usage %" field and confirmed with Enter.

4.2.5 Multi-size Mold (multiple sizes on one mold)

When the same MoldId (C020) and Machine (C004) have multiple sizes on the same sequence step, the system distributes C024 and calculates C022 proportionally:

sumPW = Σ ( C023[i] × C028[i] ) ← total part weight × pairs for all sizes on the mold
pairShot = Σ C028[i] ← total pairs across all sizes

For each size (i):
C024[i] = C024(row being weighed) ← shared C024
C022[i] = ( C024 − sumPW ) / pairShot (if C023[i] > 0, otherwise = 0)

4.2.6 Cascade Update of Subsequent Steps (ExecuteSave)

After Saving a step, the system automatically updates C021/C022 for subsequent steps that already have C024 > 0:

If item.C015 == _rowSelected.C015 (same sequence):
  item.C021 = item.C023 − _rowSelected.C023
  item.C022 = item.C024 − item.C021

If item.C015 > _rowSelected.C015 (subsequent step):
  item.C021 = item.C023 − prev.C023 (prev = immediately preceding step)
  item.C022 = item.C024 − item.C021
Cascade condition: Only applies to injection items (not REX, Stud, Inlay, Ring) and not sharing the same mold prefix with the step being saved.

4.2.7 Studs / Logo / Cleat_Ring (C036)

C036 = Round( ScaleValue / pairs, 2 ) ← when step name starts with "Studs", "Logo", or "Cleat_Ring"

4.3 Tolerance System

Values in the Reference Panel are automatically color-coded when comparing Actual vs STD (most recent weighing value from history):

LevelConditionDisplayMeaning
IDLE No STD yet or Actual = 0 Light grey No data available for comparison
OK ✓ |Δ%| ≤ 1% Green #4CAF50 Within safe threshold
WARN ⚠ 1% < |Δ%| ≤ 3% Orange #FF9800 Warning – needs attention
ERROR ✗ |Δ%| > 3% Red #F44336 Out of tolerance – requires review
Δ% = ( Actual − STD ) / STD × 100

The ScaleCard (large scale number frame) changes background and border color based on the worst-case tolerance level among the 4 Reference Rows.

7. Step-by-Step User Guide

7.1 Basic Weighing Workflow (Injection items)

#ActionExpected Result
1Scan RFID card or type Employee ID then EnterEmployee Name auto-fills. UserName on titlebar updates.
2a[Optional] Scan QR Code label with barcode gunCorresponding step is auto-selected in LookUpEdit. Step Information fills automatically.
2b[Or] Select Step in LookUpEdit (type name/code, filter, click)Step Information auto-fills. TOTAL STEPS grid shows full BOM.
3Check TOTAL STEPS grid, verify "Active" step (blue dot)Confirm the correct step to weigh.
4Place entire shot on scale (part + runner)Scale Card shows total weight. Check "Stable" badge.
5Press [↓ Save] 1st timeC024 = scale value. Grid "Total Weight Injection" column updates.
6Remove runner, place only the part on scaleScale Card updates with new value.
7Press [↓ Save] 2nd timeC023/C021/C022 are calculated. Reference Panel compares against STD and color-codes by tolerance.
8Repeat steps 2b–7 for remaining steps (click [Scale] on each row)All steps show Done (green dot).
9Press [Confirm]Validation checks → write to DB → success message → reset session.

7.2 Weighing Non-Injection Material (REX items)

  • Select a step with code starting with "REX" (Nonwoven, Mesh, Receptacle...).
  • If Partial (Nonwoven/Mesh): Check the Usage % field – enter the correct percentage then Enter before pressing Save.
  • Place the material on the scale → press [↓ Save] (only once).
  • The system automatically calculates usage/unusage using the Partial or Full formula.

7.3 Adjusting Partitioning (Adj.)

  • Tick the Adj. checkbox next to the Partitioning field to enable edit mode.
  • Enter the new pairs/shot value then press Enter.
  • The system updates C028 and recalculates related values.
Note: Only adjust when there is a mold change or special order. Default value comes from FT601.

7.4 Manual Scale Value Entry

  • When the digital scale is disconnected or EnableReadScale=false: the Scale Value field can be typed manually.
  • Only numeric characters and . are accepted – other characters are blocked with a yellow warning tooltip.
  • Press Enter in the Scale Value field → system processes it as if a value was received from hardware.

8. System Configuration (ConfigSystem)

Configuration is stored in table FT608 keyed by MachineName, in JSON format (ConfigModel). Accessed via GlobalVariable.ConfigSystem.

ConfigurationEffect
Scanner.Enable / Scanner.ReadOnlyEnable/disable Barcode scanner (Zebra CoreScanner SDK). ReadOnly = read only, do not process.
RFID.Enable, Rfid_Com, Rfid_AutoFindCom, Rfid_Caption, Rfid_ManufactConfigure RFID reader via COM port. AutoFindCom=true = auto-find COM by Caption/Manufacturer.
Scale.Enable, IP, Port, TimeScan (ms), CalibZero, CalibGain, DecimalNum, ModelName, CheckStable, CheckTareConfigure digital scale via TCP/IP. TimeScan = polling interval. CalibZero/CalibGain = calibration.
EnableReadScaletrue = use hardware scale (ReadOnly TextBox); false = manual entry (editable TextBox)
PercentOfUserNonWovenDefault usage percentage for Nonwoven/Mesh (e.g., 70)
CategoryOfNonInjectionUsagePartialList of CategoryCodes applying the Partial formula (Nonwoven, Mesh, ...)
UpdatePathXML file URL for AutoUpdaterDotNET to check for new versions
Note: If no configuration is found for the current MachineName, the system automatically creates a new record with default ConfigModel in FT608.
